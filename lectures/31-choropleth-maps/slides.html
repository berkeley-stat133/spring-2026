Choropleth Maps

  • Choropleth
    • khôros: area
    • plêthos: multitude
  • Used to produce thematic maps
  • Geographic regions color coded in relation to a variable:
    • quantitative
    • categorical
  • It’s basically a map composed of colored polygons.

Color Schemes

Color scale functions in "ggplot2"

  • scale_fill_continuous(): color scale for conitnuous data values using a continuous color spectrum

  • scale_fill_binned(): assign discrete color bins to the continuous scale

  • scale_fill_gradient(): two colour gradient (low-high)

  • scale_fill_gradient2(): diverging color gradient (low-mid-high)

  • scale_fill_gradientn(): n-color gradient

  • scale_fill_steps(): two color binned gradient (low-high)

  • scale_fill_steps2(): diverging binned color gradient (low-mid-high)

  • scale_fill_viridis_b(), scale_fill_viridis_c(), scale_fill_viridis_d()

Purple Color Scheme

To have a color scheme similar to the plot in Forbes’ article, we can use scale_fill_gradient() which creates a two colour gradient (low-high)

joined_inner |>
  ggplot() +
  geom_sf(aes(fill = Average), color = "white") +
  scale_fill_gradient(low = "#1b4bab", high = "#d7e1f5") +
  theme_void()

Another Purple Color Palette

We can also use scale_fill_gradient(). In this case we borrow one of the color schemes from the package "RColorBrewer": the "Purples" scheme

https://colorbrewer2.org/#type=sequential&scheme=Purples&n=9

joined_inner |>
  ggplot() +
  geom_sf(aes(fill = Average), color = "white") +
  scale_fill_gradientn(colors = brewer.pal(n = 7, name = "Purples"), 
                       breaks = seq(45000, 80000, by = 5000)) +
  theme_void()


In contrast to the map in Forbes, we prefer to have dark hues for higher average salaries, and light hues for lower average salaries.

Our workflow

Interactive Map

Interactive map with "ggiraph"

We can make it interactive by using geom_sf_interactive() and activating the tooltip argument inside the aesthetic mappings.

Code 
# adding interactivity with "ggiraph" functions
gmap = joined_inner |>
  mutate(Label = paste0(full, ": ", Average)) |>
  ggplot(aes(fill = Average,
             tooltip = Label)) +
  geom_sf_interactive(color = "white") +
  scale_fill_gradientn(colors = brewer.pal(n = 7, name = "Purples"), 
                       breaks = seq(45000, 80000, by = 5000)) +
  theme_void()

girafe(ggobj = gmap)
